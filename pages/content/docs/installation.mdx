### Add the dependency

Fragment is published on the [Wally](https://wally.run/) registry. Add it to your `wally.toml`:

```toml title="wally.toml"
[dependencies]
Fragment = "chteau/fragment@0.1.0"
```

Then run `wally install`. Fragment installs into wherever your `Packages` folder is synced (typically `ReplicatedStorage.Packages`), so it's required from there:

```luau
local Fragment = require(ReplicatedStorage.Packages.Fragment)
```

<Callout title="Storybook adapters included" type="info">
    The [Flipbook](https://devforum.roblox.com/t/2184387) and [UI Labs](https://ui-labs.luau.page) adapters install as part of the package too — `ReplicatedStorage.Packages.Fragment.Integrations.Flipbook` / `.UILabs`. See the [Storybook guide](/storybook).
</Callout>

## Initialize Fragment

Create `FragmentLoad.client.luau` as a `LocalScript` inside your project folder. Pass a structured table to `Fragment.load` so every folder is required in the correct dependency order with no race conditions.

```luau title="FragmentLoad.client.luau"
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Fragment = require(ReplicatedStorage.Fragment)

Fragment.load({ -- [!code highlight]
    Stores     = script.Parent.Stores, -- [!code highlight]
    Contexts   = script.Parent.Contexts, -- [!code highlight]
    Hooks      = script.Parent.Hooks, -- [!code highlight]
    Components = script.Parent.Components, -- [!code highlight]
    Handles    = script.Parent.Handles, -- [!code highlight]
}) -- [!code highlight]
```

`Fragment.load` walks every folder recursively, requires every `ModuleScript` it finds, then runs an initial render pass on all registered Handles. The structured form guarantees that Stores are registered before Contexts, Contexts before Hooks, Hooks before Components, and Components before Handles — so no module can reference something that has not been registered yet.

<Callout title="All keys are optional" type="info">
    You only need to include the folders that exist in your project. Omitting a key is safe.
</Callout>

## Legacy single-folder usage

If you already have a project that loads a single folder, that call still works unchanged.

```luau title="FragmentLoad.client.luau"
Fragment.load(script.Parent.Handles)
```
